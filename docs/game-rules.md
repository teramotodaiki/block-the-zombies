# ゲームルール & エンティティ仕様

## フィールド・タイル

- フィールド：
  - 2D グリッド（タイルベース）のステージ。
  - 幅・高さはレベルごとに異なる（具体的な数値は TBD）。
- タイル種（論理的なもの）：
  - 空（何もない）
  - 地面（歩けるブロック）
  - ベッドロック（破壊不可の固いブロック）
  - マグマ（触れると村人・ゾンビともにアウト）
  - ゴール（家）の位置を示すタイル
- 理由：
  - タイル種を少数に絞ることで、レベル設計と実装のシンプルさを保つため。

## エンティティ：村人

- 行動：
  - 横方向に自動で歩き続ける。
  - 進行方向の前にブロックがあれば反転する。
  - 高さ 1 段までの段差は登れる。2 段以上は登れない。
  - 足元が空であれば落下する。
- 反応：
  - ゾンビに触れるとアウト（ゾンビ化して消えるなどの表現）。
  - マグマに触れるとアウト。
- 目的：
  - ゴールの家タイルに到達すると「家の窓を1つ光らせる」。
- 制約：
  - 画面内に同時に存在できる村人は最大 3 人まで。
  - 3 人いる間は、新しい村人はスポーンしない（1人減るまで待機）。

理由：
- シンプルなルールでレミングスらしい「群れ制御」の面白さを出したいため。

## エンティティ：ゾンビ

- 行動：
  - 基本ルールは村人と同じ（歩く・反転・落下）。
  - プレイヤーキャラではなく、村人を追い詰める“移動する罠”。
  - 村人と同様（直進・壁で反転）で実装する。
- 反応：
  - マグマに触れると消える（ご褒美演出）。

理由：
- 分かりやすい脅威となりつつ、ブロック配置で状況をコントロールできるようにするため。

## ブロック（プレイヤーの設置ブロック）

- 種類：
  - プレイヤーが置けるブロックはまず 1 種類（石ブロック）から始める。
- ルール：
  - タップでブロックを置く／壊す。
  - フィールド上に同時に存在できるブロック数に上限がある。
  - ブロックを壊すと、その分だけ再び置けるようになる（「所持数が戻る」イメージ）。

理由：
- 上限を設けることでレベルデザインの制御が容易になり、
  「全部埋めて終わり」みたいな解法を防ぐため。

## ブロック設置条件（マイクラ的制約）

- 置ける条件（論理）：
  - 対象タイルが空である。
  - 対象タイルが建設禁止指定でない。
  - 対象タイルの上下左右のいずれかに、何らかの固体ブロック
    （地面／ベッドロック／プレイヤーブロック）が存在する。
  - 現在フィールド上に存在するブロック数が上限未満である。
- 壊せる条件：
  - そこがプレイヤーブロックである。
  - ベッドロック等は壊せない。

理由：
- マイクラ的な「空中ブロック禁止」を再現しつつ、
  ステージの自由度とパズル性を両立させるため。

## 勝敗・進行

- クリア条件：
  - ゴールの家に到達した村人が一定数に達する。
  - HUD の人型アイコンで進捗を表現し、規定数が緑色になったらステージクリア。
- 失敗・リトライ：
  - このゲームにゲームオーバーはありません。村人はずっと出続けます。
  - プレイ中は何度でもリトライできます。

理由：
- 罰よりも「試行錯誤をもう一回やってみる」モチベーションを重視するため。
