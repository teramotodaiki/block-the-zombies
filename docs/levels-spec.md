# レベルデータ仕様

1 レベルにつき 1 つのTSファイルを作成する。
以下の構造を TypeScript の型としてコード側に定義し、その型に従うようにする。

## レベルデータの責務

1 ステージ（1 レベル）を表す「設定オブジェクト」として、以下の情報を持つ：

- ステージのサイズ（幅・高さ）
- バイオーム ID（見た目・BGM の切り替え用）
- 初期タイル配置（空・地面・ベッドロック・マグマ・ゴールなど）
- 村人のスポーン条件（開始位置・間隔・人数）
- ゾンビのスポーン条件（位置・タイミング）
- ゴール条件（必要な村人の数）
- ブロック設置ルール（上限個数・建設禁止マス）

理由：
- ルールやエンジンのコードを書き換えずに、
  レベルのバリエーションを増やせるようにするため。

## 抽象構造（コードではなく概念）

レベル定義は、少なくとも以下の概念を含むこと：

- ステージ基本情報
  - id: レベルを一意に識別する ID（ファイル名と一致させる）。
  - biome: 利用するバイオーム（草原・砂漠など）を表す ID。
  - width, height: タイルグリッドのサイズ。

- タイル配置
  - tiles: グリッド全体のタイル種情報。

- スポーン情報
  - 村人スポーン：
    - 位置（グリッド座標）
    - 出現間隔（ミリ秒など単位は一貫させる）
    - 出現する総数
  - ゾンビスポーン：
    - 位置（グリッド座標）
    - 出現タイミング（ステージ開始からの経過時間など）

- ゴール条件
  - ゴールとなる家の位置（グリッド座標）
  - そこに到達すべき村人の数

- ブロック設置ルール
  - フィールド上に同時に存在できるプレイヤーブロック数の上限。
  - 建設禁止タイルの座標リスト（あれば）。
