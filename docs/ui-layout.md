# 画面構成・UI レイアウト仕様

## 共通ルール

- 画面内にはテキスト・数字を描画しない。
- UI は主に画面上部の HUD バーに集約する。
- フィールド部分（タイルを置く範囲）は画面中央〜下側に広く確保する。
- ブラウザのアドレスバーや Android ナビバーを考慮し、
  画面下端付近には重要 UI を置かない。
- UI はすべて Phaser で作成する。

理由：
- タブレット環境で誤タップによる OS UI 呼び出しと混ざるのを避けるため。
- 子どもが UI を見失いにくいよう、上部にまとめておくため。

## ゲーム画面の HUD 構成

画面上端中央に HUD バーを配置する。

- 左側：
  - ポーズボタン（「||」アイコン）： タップするとポーズメニュー（オーバーレイ）を表示。
- 中央〜右側：
  - ゴール進捗： 村人の到達状況を人型アイコン（グレー／緑）で表示。
  - ブロック残量： ブロックアイコン ＋ 数字（残り個数）。

### ホーム・リスタート・ポーズ

- プレイ中の誤操作を防ぐため、ホーム遷移やリスタートは「ポーズメニュー」内に集約する。
- ポーズボタンをタップ → メニューオーバーレイ表示（ここに Resume / Retry / Home ボタンを配置）という 2 ステップ構成とする。

## タイトル・マップ・クリア画面

- タイトル
  - 真ん中にゲームのメインイラスト。
  - 画面全体をタップしてスタート。ボタンは配置しない。
- バイオーム選択（TBD: 今回は実装省略、LevelSelectSceneへ統合）
- レベル選択
  - ステージノードを並べる。
  - 未開放レベルは鍵アイコンでロック表示。
  - クリア済み・開放済みレベルは選択可能。

- クリア画面
  - バックのゲーム画面を暗くして、その上にオーバーレイ。
  - 「LEVEL CLEAR」の文字とアクションボタン。
  - 「Next」ボタン： レベル選択画面へ戻る（次のレベルがアンロックされる）。
  - ホームやリトライが必要な場合は、プレイ中のポーズメニューを使用する（クリア後はNextのみでシンプルに）。
