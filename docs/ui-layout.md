# 画面構成・UI レイアウト仕様

## 共通ルール

- 画面内にはテキスト・数字を描画しない。
- UI は主に画面上部の HUD バーに集約する。
- フィールド部分（タイルを置く範囲）は画面中央〜下側に広く確保する。
- ブラウザのアドレスバーや Android ナビバーを考慮し、
  画面下端付近には重要 UI を置かない。

理由：
- タブレット環境で誤タップによる OS UI 呼び出しと混ざるのを避けるため。
- 子どもが UI を見失いにくいよう、上部にまとめておくため。

## ゲーム画面の HUD 構成（案）

画面上端中央に HUD バーを配置する。

- 左側：
  - ホームボタン（家アイコン）
  - リスタートボタン（円矢印アイコン）
  - ポーズボタン（「||」アイコン）
- 中央〜右側：
  - ゴール進捗（家アイコン＋窓の点灯状況）
  - ブロック残量バー（石ブロックアイコン列）

### ホーム・リスタートの誤タップ対策

- ホーム：
  - ワンタップで即遷移させず、
    長押しまたは 2 ステップ確認を行う（どちらにするかは TBD）。
- リスタート：
  - 同様に、誤タップで即リセットしないように、
    軽い確認挙動（長押し・ポップアップ）を入れることを検討（詳細は TBD）。

理由：
- ゲーム中に誤タップでプレイが中断・リセットされると、
  子どもにとってストレスが大きいため。
- ただし操作フローを複雑にし過ぎないよう、
  実際のプレイ感を見ながら調整するため。

- バイオーム選択
  - カード型 UI を横に並べる。
  - 開放済みのものだけフルカラーで表示。未開放は鍵アイコン＋グレー。
- レベル選択
  - バイオーム内のステージを線でつないだノードとして表示。
  - 次に遊べるステージだけ、ノードをアニメーションさせて強調。

  - バックのゲーム画面を暗くして、その上にオーバーレイ。
  - 真ん中に家アイコンと「窓が全部光った」演出。
  - 真ん中に家アイコンと「窓が全部光った」演出。
  - 下に 1 つのボタン（次ステージ）。アイコンのみ。
  - ホームやリトライは HUD にあるボタンを使用する。
